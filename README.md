 系統架構與演算法 (Calculation Engine Architecture)

1. 立春換年：精確計算太陽黃經 315° 交節時間（而非正月初一）。
2. 節氣換月：精確計算 12 節氣交界時刻決定月支（寅月立春、卯月驚蟄等）。
3. 日柱計算：基於天文儒略日（Julian Day / JDN）進行 60 甲子循環錨定。
4. 子時規則：支援 `ZI_START_NEXT_DAY`（23:00 起進入下一日）與 `ZI_START_SAME_DAY`。
5. 五虎遁 & 五鼠遁：演算法動態推導月干與時干。
6. 十神與十二長生：完整推算四柱天干與支藏天干之十神定位及長生十二階段。
7. 干支生剋合沖：天干五合、地支六合、三合、三會、六沖、相刑、相害、相破。
