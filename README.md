## 系統架構與演算法 (Calculation Engine Architecture)

本系統嚴格遵循 **Deterministic（100% 固定可重複）** 規範，不依賴 AI 猜測四柱：
1. **立春換年**：精確計算太陽黃經 315° 交節時間（而非正月初一）。
2. **節氣換月**：精確計算 12 節氣交界時刻決定月支（寅月立春、卯月驚蟄等）。
3. **日柱計算**：基於天文儒略日（Julian Day / JDN）進行 60 甲子循環錨定。
4. **子時規則**：支援 `ZI_START_NEXT_DAY`（23:00 起進入下一日）與 `ZI_START_SAME_DAY`。
5. **五虎遁 & 五鼠遁**：演算法動態推導月干與時干。
6. **十神與十二長生**：完整推算四柱天干與支藏天干之十神定位及長生十二階段。
7. **干支生剋合沖**：天干五合、地支六合、三合、三會、六沖、相刑、相害、相破。
8. **神煞系統**：天乙貴人、文昌、桃花、驛馬、華蓋、將星、太極貴人、福星貴人、天德、月德、紅鸞、天喜、孤辰、寡宿、亡神、劫煞、災煞、白虎等。
9. **大運與流年**：陽男陰女順行、陰男陽女逆行，起運歲數精準至月日，生成 8 步十年大運。

## 部署與運行指引 (Deployment Guide)

### 方式一：Docker Compose 一鍵部署 (推薦生產環境)

```bash
# 1. 進入專案目錄
cd /Users/leo/.gemini/antigravity/scratch/ding-manshan-bazi

# 2. 構建並啟動所有容器 (Frontend + Backend + Nginx)
docker-compose up -d --build

# 3. 檢查運行狀態
docker-compose ps
```
* **前端介面**：`http://localhost:3000` (或 80 埠)
* **後端 API 文檔**：`http://localhost:8000/docs`

---

### 方式二：本地開發模式 (Local Development)

#### 1. 啟動後端 (FastAPI)
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### 2. 啟動前端 (React + Vite)
```bash
cd frontend
npm install
npm run dev
```
前端將在 `http://localhost:3000` 運行，並自動反向代理 `/api` 請求至後端。

---

### 方式三：雲端 VPS / 主機獨立部署 (Ubuntu / Debian / Rocky Linux)

#### 1. 安裝基礎環境
```bash
sudo apt update && sudo apt install -y python3 python3-pip python3-venv nodejs npm nginx
```

#### 2. 部署後端 (Systemd 守護進程)
創建 `/etc/systemd/system/bazi-api.service`：
```ini
[Unit]
Description=Bazi API Service
After=network.target

[Service]
User=www-data
WorkingDirectory=/var/www/ding-manshan-bazi/backend
ExecStart=/var/www/ding-manshan-bazi/backend/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
Restart=always

[Install]
WantedBy=multi-user.target
```
啟動服務：
```bash
sudo systemctl daemon-reload
sudo systemctl start bazi-api
sudo systemctl enable bazi-api
```

#### 3. 構建前端並配置 Nginx
```bash
cd frontend
npm install && npm run build
sudo cp -r dist/* /var/www/ding-manshan-bazi/frontend-dist/
```

配置 `/etc/nginx/sites-available/bazi.conf`：
```nginx
server {
    listen 80;
    server_name yourdomain.com;

    # 前端 SPA
    location / {
        root /var/www/ding-manshan-bazi/frontend-dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 後端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
啟用配置並重載 Nginx：
```bash
sudo ln -s /etc/nginx/sites-available/bazi.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

#### 4. 配置 SSL 證書 (Let's Encrypt Free HTTPS)
```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com
```
